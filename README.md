### 💡 Core Philosophy

> **"Harness engineering over prompt engineering."**

Rather than hand-tuning fragile, one-off prompts, my work focuses on building **disciplined operating environments** for AI agents. By engineering structured runtime hooks, multi-role reviewer dispatch, bounded skill workflows, and deterministic verification gates, we can keep autonomous models firmly on the rails across complex software engineering sessions.

Whether designing agent plugins, constructing citation-backed knowledge pipelines, or building enterprise PHP/Laravel ecosystems across 19-cell version matrices, the objective remains the same: **reproducibility, zero-hallucination rigor, and rock-solid architectural durability.**

### 🔒 Privacy-First Systems & Personal Automation

> End-to-end data pipelines running locally so sensitive personal and financial data never leaves your machine.

- [**ccas**](https://github.com/hmj1026/ccas) — **Credit Card Automation System (CCAS)**:
  - Ingests encrypted monthly PDF e-statements from Gmail via OAuth across **7 Taiwanese banks** (CTBC, E.SUN, Taishin, UBOT, Cathay, SinoPac, Fubon).
  - Decrypts, extracts line items, and classifies transactions with prioritized regex matching (featuring a 100ms fail-soft timeout).
  - Surfaces data through a self-hosted **REST API, React dashboard, and Telegram bot** with budget threshold alerts (80% / 100%) and bill due-date reminders.
  - Fully containerized with Docker Compose; production hardening includes HMAC-signed session cookies and secret-redacting structured logging.
- [**Line_Parser**](https://github.com/hmj1026/Line_Parser) & [**line_parser_py**](https://github.com/hmj1026/line_parser_py) — High-throughput parser for LINE group chat exports, structuring raw conversational logs into searchable data streams.
- [**line-bot**](https://github.com/hmj1026/line-bot) — Interactive LINE messaging bot service for alerts, queries, and event dispatch.
